Gerador de configuração

Escolha Cisco ou MikroTik, defina portas, VLANs, WAN e segurança. O script aparece ao lado, pronto para copiar e aplicar.

Plataforma

Gerador de configuração Cisco IOS/IOS XE

Defina portas, VLANs, WAN e segurança. A configuração Cisco IOS/IOS XE aparece ao lado, pronta para copiar e aplicar.

Plataforma Cisco

Portas

Clique numa porta e escolha a função. A cor de cada porta de acesso é a cor da VLAN.

Porta
Função
WAN: saída para a Internet WAN 2: failover Tronco: todas as VLANs com tag Acesso: uma VLAN sem tag Livre: porta desativada

VLANs

Configure as VLANs e, se necessário, informe os servidores DHCP para gerar ip helper-address na SVI. Se o campo de DHCP Relay ficar vazio, nenhum helper será gerado.

ACLs personalizadas

Crie uma ACL nomeada, escolha a interface e o sentido (IN/OUT). Informe uma regra Cisco por linha.

Internet (WAN)

Tipo de conexão

Failover ()

A WAN principal tem prioridade; esta porta assume automaticamente quando a principal cai. Se as duas forem DHCP ou PPPoE, a troca ocorre quando a interface ou a sessão cai — não quando o link continua ligado mas sem Internet. Para detectar isso de forma confiável, use IP fixo em pelo menos uma das duas.

Como aplicar

  1. Se o roteador está em produção, faça backup antes: /system backup save.
  2. O script parte de um roteador zerado. Para zerar: apague a configuração somente se isso for realmente necessário.
  3. Conecte pelo CLI/console Cisco (por MAC) numa porta que ficará como acesso à VLAN de gerência e ative o Modo Seguro (Ctrl+X no terminal). Se a conexão cair, o roteador desfaz as mudanças.
  4. Salve o texto como config.txt, arraste o arquivo para Files no CLI/console Cisco e execute /import file-name=config.txt verbose=yes. Colar direto no terminal pode truncar scripts longos.
  5. Confirme o acesso pela VLAN de gerência, saia do Modo Seguro e troque a senha do admin, se não criou outro usuário.
